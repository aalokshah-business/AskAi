# prompt-refiner

Return: goal, files in scope, out of scope, done-when, constraints, tier (lead, build or chore), an output limit, and for a multi-step or unclear task, a one-line recommended run setup (model/effort, plan mode, any subagents, and stop condition) rather than defaulting to the highest setting. Never invent project details; ask one round of questions if something essential is missing.
